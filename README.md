# 🐺 WolfEye - Tactical AI Vision & Smart Classroom Web App

نظام المراقبة والتحكم الذكي المستوحى من هوية **Wolfteam** بتصميم تكتيكي احترافي يجمع بين اللونين **الأسود والأصفر الفاقع** مع واجهة مستخدم ذات طابع عسكري مستقبلي (Cyberpunk / Tactical HUD) ومؤثرات حركية وصوتية مدمجة.

---

## 🌟 مميزات الموقع الرئيسية

### 1. شاشة البداية التكتيكية (Tactical Splash Screen)
- **الهوية والشعار:** يعرض شعار المشروع **WolfEye** بدقة عالية مع حلقات ميكانيكية دائرية متحركة (Mechanical Iris HUD Rings) مستوحاة من عدسات الرصد التكتيكية.
- **Boot Sequence Terminal:** محاكي لأوامر الإقلاع التكتيكية بالذكاء الاصطناعي وربط الحساسات وقاعدة البيانات.
- **عداد التحميل التزامني:** شريط تقدم ديناميكي مضيء بنسبة مئوية تنبض باللون الأصفر.
- **الانتقال المميز للـ Home (Aperture Wipe Transition):** عند الضغط على زر الدخول أو بعد انتهاء التحميل، تنفتح عدسة الـ Iris بموجة صدمية سينمائية (Shockwave) مع مؤثر صوتي احترافي (Shutter Whoosh) ليكشف عن لوحة التحكم الرئيسية بانسيابية فائقة.

### 2. لوحة التحكم الحية (Live Telemetry & Circular Gauges)
- **دواير المراقبة الحية (HUD Circular Gauges):**
  1. **عدد الطلاب / المتواجدين (`people_count`):** عداد دائري تفاعلي يتتبع عدد الأفراد المكتشفين بنموذج YOLO11 ByteTrack، مع حالة السعة (Empty / Optimal / High Density).
  2. **حالة الإضاءة الذكية (`led_is_on`):** عداد دائري للإضاءة الآلية مع توهج نيون أصفر، يعرض وقت التشغيل بالثواني (`led_on_seconds`) وحساب الطاقة الموفرة بالكيلوواط/ساعة (kWh).
  3. **درجة الحرارة (`temperature_c`):** عداد حراري يقرأ بيانات حساس LM35، ويتغير لونه تلقائياً للأحمر الخطر عند بلوغ أو تجاوز حد الخطر (45°C).
  4. **مستشعر الغاز (`gas_detected`):** مؤشر أمان دائري لمستشعر MQ-5 (0: آمن / 1: تسريب غاز)، يدخل في وضع الإنذار فورياً عند استشعار الخطر.
- **Classroom Radar Simulation:** رادار تكتيكي متحرك يحاكي منطقة المراقبة (ROI Zone) وتتبع الأفراد المكتشفين في الفيديو.
- **مواصفات العتاد:** بطاقة تعرض منافذ الأردوينو (COM5)، موديل YOLO المستخدم، ومؤقت الإطفاء الآلي (10 ثواني).

### 3. سجلات المراقبة الدورية (Monitoring Logs History - كل 3 دقائق)
- جدول تكتيكي يعرض البيانات الواردة من جدول `monitoring_logs` المحدث كل 180 ثانية (3 دقائق).
- يدعم:
  - البحث الفوري بالرقم التعريفي أو عدد الطلاب أو درجة الحرارة.
  - الفلترة حسب حالة الإضاءة (ON / OFF).
  - تصدير البيانات بنقرة واحدة إلى **CSV** أو **JSON**.
  - تقليب الصفحات (Pagination).
  - زر إضافة سجل اختباري فوري لتجربة النظام دون انتظار الدقائق الثلاث.

### 4. جدول الإنذارات والتنبيهات (Hazard & Safety Alerts)
- جدول خاص بالتنبيهات اللحظية من جدول `alerts` الخاص بتسريب الغاز (`GAS_LEAK`) أو درجات الحرارة المرتفعة (`HIGH_TEMPERATURE`).
- بنر إنذار أحمر متوهج ينبض عند وجود خطر مع إمكانية تأكيد وإنهاء البلاغ (`Acknowledge / Resolve`).
- أزرار اختبار ومحاكاة فورية:
  - **TEST GAS ALERT:** محاكاة تسريب غاز وإطلاق صفارة الإنذار.
  - **TEST TEMP ALERT:** محاكاة حرارة مرتفعة (48.5°C).

### 5. التحليلات الذكية واستهلاك الطاقة (AI & Energy Analytics)
- رسوم بيانية تفاعلية باستخدام **Chart.js** بألوان نيون تكتيكية:
  - منحنى كثافة وتواجد الطلاب خلال آخر فترات زمنية.
  - التدرج الحراري للغرفة لرصد أي تغيرات بيئية مفاجئة.

### 6. نظام الصوت التكتيكي (Procedural Web Audio API)
- تم بناء مولد صوتي رقمي خالص بدون ملفات خارجية ثقيلة، يولد أصوات النقر، فتح العدسة التكتيكي، وصفارات الإنذار ونغمات التزامن مع زر لكتم وتفعيل الصوت وحفظ الحالة.

## 🚀 طريقة التشغيل

يمكنك فتح الموقع بأي من الطرق التالية:
1. **تشغيل سيرفر محلي (موصى به):**
   ```bash
   cd wep_app
   python -m http.server 5500
   ```
   ثم الدخول إلى الرابط: [http://localhost:5500](http://localhost:5500)
2. **أو فتح ملف `index.html` مباشرة في أي متصفح حديث.**
